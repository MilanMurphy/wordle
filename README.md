IMPORTANT
To run the program properly, wordleV4.py must be ran
in a folder containing wordlist.csv, wordPriority.csv, and wordBank.csv in their unmodified
formats. The program will not work otherwise, and they should be included in the
download. The program is meant to be ranin spyder v6.

This folder contains all the resources that were used in the creation of my project.
The completed project is wordleV4.py. wordleV4.py allows you to play wordle, as well as
give words to the computer solver for it to solve. For a fun challenge
try to find words that the solver loses to!  If you would like to compete against my solver, start by playing a
game by running GAME in the main menu. After completing your game, input the 
final word into the solver, and see if it takes more or less turns than you.

Instructions on operating the program will appear in the console when it is opened.
Make sure to have the 'plot' pane open! Type HELP as your first input for futher
explination on how the program works.

The BestWordFinder programs are the programs I used to generate my data for wordPriority.csv.
Wordle V1-V3 document the development process.
