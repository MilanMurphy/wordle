By Milan Murphy, for the Ualberta ENCMP 100 Fall 2026 contest.

This repo contains all the resources that were used in the creation of my project.
The completed project is wordleV4.py, the other files are the different
versions of the project from during its creation, or made during the optimization
of the guessing algorithm. wordleV4.py allows you to play wordle, as well as
give words to the computer solver for it to attempt to solve. For a fun challenge
try to find words that the solver loses to! The program is meant to be ran
in spyder.

Instructions on operating the program will appear in the console when it is opened.
Make sure to have the 'plot' pane open! Type HELP as your first input for futher
explination on how the program works.
